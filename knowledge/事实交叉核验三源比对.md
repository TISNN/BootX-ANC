# 事实交叉核验三源比对

## 一句话
对外文档里的工商/企业事实必须做 QCC / 启信宝 / 官网 三源比对、取可信集；对外版只用「约 / 多家」口径，绝不直接印冲突数字。

## 详情
- 工商数据在 QCC / 启信宝 / 官网 之间经常冲突，这是最容易被省掉、却最关键的一步。
- 做法：三源比对 → 取可信集合；对外文档用「约 / 多家 / 团队约 30 余人」模糊口径；精确但未核实的数字留在**内部版**。
- 顺手修明显错别字（曾见「横景」→ 应为「横琴」）。

## 怎么用
任何要写进客户对外文档的企业事实、数字、成立日期，先跑三源核验再落笔；遇到冲突用模糊口径 + 内部留精确值。可作为 `skills/bootx-requirements-plan` 的强制前置步骤。
