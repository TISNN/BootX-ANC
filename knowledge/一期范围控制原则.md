# 一期范围控制原则

## 一句话
一期目标定为「验证财税客服闭环」，不一次性替换现有财务软件 / CRM / 人工流程；二期内容不占用一期范围与报价，按效果分步推进。

## 详情
- **决策**：威吉瑞项目一期聚焦验证「财税客服闭环」（知识大脑 + 员工助手 / 客服 AI + 服务标准化 / 客户交付流程智能化 / AI 自媒体运营与生成四个场景），而非大包大揽替换客户现有系统。
- **理由**：降低交付风险与首期投入，用可见效果换取二期深入自动化（自动报税、写入电子税务局、修改金财代账等逐项标注前提）；二期按效果分步推进，不提前占用一期预算与范围。
- **约束**：个人微信自动化明确不纳入一期承诺（见 `knowledge/个人微信客服工程落地与封号风险.md`）。

## 怎么用
给任何处于意向/首期的客户做方案时，默认采用「小范围验证闭环 → 按效果扩二期」的分期策略；避免在首期许诺需要大替换或受平台限制的泛化能力。
