# 50_skills · Agent 技能库

被验证有效的知识进一步固化为 Agent 技能（Skill），分发到全员。

**这是飞轮最高形态**：不是"让 AI 知道"，而是"让 AI 能干"。

每个技能一个子目录，含 `SKILL.md`（及可选 `references/`、`scripts/`、`assets/`），遵循 WorkBuddy Skill 格式。

固化标准：某条知识被 ≥3 次不同人复用且验证有效，即可从 `30_actions/` 或 `40_knowledge/` 提炼入此目录。

命名：`skill-主题/`，例：`skill-requirements-plan/`、`skill-weekly-clean/`。
