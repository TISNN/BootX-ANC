# 文档结构（8 段式大纲）

用于「客户需求确认与方案规划书」的标准章节。顺序固定，便于客户按"背景 → 痛点 →
目标 → 模块 → 架构 → 规划 → 报价 → 下一步"阅读。所有章节标题**不要英文副标题**。

## 00 · 封面 + 一页纸结论
- 封面：客户 Logo（居中、约 3.5cm）+ 主标题 + 副标题 + 信息条（致 / 文档性质 / 阶段 / 日期）。
- 一页纸结论（卡片 3 列）：核心目标、最高优先级、启动方式。
- 首期投入参考（callout gold）：明确"已确认口径"下的首期报价 + 单列项说明。

## 01 · 关于客户（背景整理）
- 1.1 公司概况（数据表）：全称、成立时间、运营总部、服务区域、核心团队、企业规模、业务定位、服务规模。
- 1.2 四大业务板块（卡片 2 列）：财 / 法 / 税 / 国际。
- 1.3 关键数字（卡片 3 列）：服务客户数、客户触点（微信）、核心系统。
- 一句话定位 callout。

## 02 · 现状诊断与核心痛点
- 引入段：点出最突出的痛点（如"重复沟通正在吃掉产能"）。
- 痛点卡 ×4（pain 块）：标签、标题、描述、影响度（红/橙/金/灰分级）。
- 痛点与影响度一览（数据表）。

## 03 · 转型目标与核心思路
- 3.1 核心目标（卡片 3 列）：先减负 / 再分层 / 后增长。
- 3.2 方法论底色（卡片 1 列，3 条）：
  - ① Workflow-first（流程优先）：先把高频业务拆成流程节点，再让 AI 进入。
  - ② Human-in-the-loop（人在回路）：税务案件/重大风险/正式申报/报价承诺类内容默认不自动发送。
  - ③ 知识飞轮 / ANC（持续积累）：每次服务回流成企业知识，越用越好用。
- 角色定位 callout：bootx = FDE 陪跑方（不是卖工具）。

## 04 · 需求模块总览
- 模块总表（# / 需求模块 / 对应痛点 / 优先级）：M1–M8。
- M1 最高优先级，含三个联动点：客服机器人 + 企业知识库（RAG）+ 语气蒸馏。
- 4.1 模块要点（mod 块）：逐模块展开子项（sub / p / li / rich）。

## 05 · ANC 架构与知识飞轮（技术基础）
- 引入段：强调"AI 不答一次就忘"，底层是知识飞轮（ANC = AI Native Company）。
- 架构图（PNG，居中 16cm，caption 图 1）。
- 5.1 三层回流（数据表）：① 全量日志采集 ② 周期性知识清洗 ③ 技能固化分发。
- 效果佐证 callout（同类项目 RAG 命中率 5%→30%→60%，用"同类实践数据"措辞，勿当保证）。

## 06 · 分期实施规划
- P1 / P2 / P3（phase 块）：每期聚焦。
- 6.1 各模块分期与投入示意（数据表，● 标记所属期）。
- 陪跑节奏 callout（FDE 五阶段：入企诊断→蓝图设计→试点落地→组织推广→持续陪跑）。

## 07 · 报价方案与商务模式
- 7.1 模块化参考报价总表（全量视角，单位：万元）。
- 7.2 推荐首期落地方案（验证优先）：方案 A（基础验证）/ 方案 B（个人微信自动化），含总表行。
- 7.3 个人微信自动化·专项边界（warn callout）：以验证为准 / 平台风险不承诺 / 合规告知 / 发送范围受限 / 交付边界。
- 7.4 商务模式（卡片 2 列）：项目制 / 验证+试点 / 持续服务 / 扩展计费。
- 7.5 付款与变更规则（数据表）。

## 08 · 下一步与待确认事项
- 8.1 下一步计划（有序列表）。
- 8.2 待确认事项（数据表，已定项标"已定"）。
- 横琴补贴政策 callout（建议客户指定负责人提供权威口径）。
- 页脚说明栏：文档性质 + 核心目标（一人服务 100 → 500/1000 家）。

## ANC 架构图说明（供生成 SVG/PNG）
分层，自上而下：
- 应用层：AI 客服 / 客户管理 / 进度看板 / 咨询问答 / 新媒体 / 数字员工
