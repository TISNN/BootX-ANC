# 报价与商务逻辑

核心原则：**先验证、再扩展；先减负、再增长**。首期用小成本跑通价值，把风险压低，
正式报价以功能对齐后的详细工作量为准。

## 1. 模块化报价（全量视角）
按需求模块拆分，每个模块单独报价（单位：万元），便于客户按优先级组合：
M1a 客服机器人、M1b 企业知识库、M1c 语气蒸馏、M2 客户管理、M3 任务与进度、
M4 咨询问答、M5 流程标准化、M6 新媒体运营、M7 记账重构（独立立项，10+）、
M8 数字员工。合计即"全量建设价"。

## 2. 首期推荐（验证优先）
基于已确认口径（预算 ≤ 3 万、先走企业微信官方接口），首期只做**基础客服提效验证
（方案 A）**：约 **2.48–2.98 万元**，含业务流程梳理、客户管理（≤300 条/5 账号）、
待跟进、AI 客服助手（FAQ 30–50 条）、试运行报告。

## 3. 危险项必须单列（关键）
个人微信的"自动读取聊天记录 + 自动发送消息"属于**受平台规则约束的渠道自动化**，
与企业微信官方接口不同，**不能按普通项目直接承诺**。处理规则：
- 必须先行**技术可行性验证**，单独报价（如 0.98–1.58 万元），不通过则交付验证结果 + 替代方案。
- 验证通过后再进入**单账号试点**（5.0 万元起）。
- 首期（如 3 万内）**不得免费捆绑**个人微信自动化，否则技术风险与后续维护全由我方承担。
- 含该能力时首期报价 5.98–8.56 万元起（验证 + 试点）。

## 4. 专项边界（写入文档 7.3，warn callout）
- 以验证结果为准：不把需求描述直接视为已实现。
- 平台风险不承诺：平台规则 / 账号风控 / 登录状态变化造成的不可用，不属于"平台稳定性"保证。
- 合规告知义务：客户须保证有权处理相关信息，并履行对内/对客告知。
- 发送范围受限：税务案件 / 重大风险 / 报价承诺 / 正式申报类内容不得默认自动发送。
- 交付边界：交付约定范围内的系统能力，不是无限期代运营。

## 5. 商务模式（四类）
① 项目制交付（一次性开发费）② 验证 + 试点制（降低首决策门槛）
③ 持续服务（年维护费 15–20% + 知识库运营 + 技术支持）④ 扩展计费（按账号/设备/场景数）。

## 6. 付款与变更
- 技术验证：签约 60% 启动 + 提交报告 40%；未通过不自动承诺退款。
- 试点开发：50% 启动 + 30% 可用版 + 20% 验收。
- 抵扣机制：验证结束后 30 日内签正式扩展合同，可约定部分/全部验证费抵扣后续开发费。
