# 样式与语气规则（客户对外文档）

## 称呼与视角
- 一律用 **贵司 / 您**，不用"你们/你们公司/客户"。
- 文档以 bootx 作为"我方/陪跑方"视角撰写，结论性语句用"我们建议 / 我们的角色定位是"。
- 客户的自述数据（如"一人服务 100→500/1000 家""工商前期沟通占 80%""7000 个微信客户"）
  标注为"来自贵司描述"，不伪造、不夸大。

## 不要做的事（硬性）
- **不要版本号**：对外文档封面与页脚都不写"V1.0 / 版本"等（Evan 偏好）。
- **不要破折号**：`——` 一律改逗号 / 句号 / 冒号。
- **不要字面 `**`**：加粗走结构化 parts 控制，绝不能残留 Markdown 星号。
- **不要英文章节副标题**：章节号旁不写 "Executive Summary / About Weijirui" 等；
  封面也不放大写英文行。技术术语（Workflow-first / Human-in-the-loop / ANC / RAG / FDE / M1 / P1）保留，因为它们是内容。
- **不要 AI 腔**：按 humanizer-zh 削减"本质/赋能/底座/引擎/壁垒/格局/此外/围绕这一目标/
  在此基础上/关键在于/不仅/标志着"等宣传与填充词；去掉破折号处的肤浅分析、过度加粗、三段式排比。
  保留客户自述数据与专业术语的准确性。

## 配色 / 主题
- 默认 **黑金主题**：主色近黑 `#1C1C1E`，辅色金 `#C98A2D`，浅底 `#EFEFEF`、
  背景 `#F7F7F7`、边框 `#E0E0E0`、弱化字 `#6B6B6B`。
- 不要深蓝作主题色（客户反馈"更丑"）。如需换色，优先炭灰+金 / 酒红，避开蓝色系。
- 客户 Logo 多为蓝红调，黑金文档不与 Logo 抢色，最稳。
- 优先级 / 影响度用彩色标签：最高=红 `#B02323`、高=橙 `#C0392B`、中=金 `#C98A2D`、低=灰。

## Logo 与版式
- 封面插入**客户 Logo**（居中、约 3.5cm、置于标题上方）。
- 优先用高清版（≥300×300、透明底 PNG 或 SVG）；32×32 小图标放大后会糊，需提醒替换。
- 封面信息条、章节号块、表头用主题主色；卡片标题用主色，正文用墨色 `#1C1C1E` 或弱化灰。
- 方块（卡片 / 痛点卡 / callout）不要过高：段间距收紧、行距 1.15–1.2，章节号块去除英文后自然变矮。

## 术语校正
- "横景补贴政策"→"横琴（粤澳深度合作区）补贴政策"。
- 创始人 / 法定代表人 / 对外品牌名须交叉验证（如"罗祖威"与品牌名"税罗汉"为同一人），
  错配会显得不专业。
