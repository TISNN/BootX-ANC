# 威吉瑞 · 财税企业 AI 转型 客户背景与需求文档

> 面向功能对齐与开发报价：梳理企业现状、核心痛点、改进需求与分期规划，作为双方共创与交付的基线。
>
> 合作阶段：意向已确认，待功能对齐与报价 · 核心目标：一人服务 100 家 → 500 / 1000 家 · 文档版本 v1.1

## 一、项目概览

**客户公司：威吉瑞**，一家提供全链路财税服务的机构，业务覆盖企业从工商设立到日常经营、再到税务风险处理的完整生命周期。当前核心诉求是借助 AI 提升服务人效与组织效能，把"一人服务 100 家客户"的产能提升到 500 甚至 1000 家。

**合作阶段：** 目前与客户仅确定了合作意向，尚未进行具体功能沟通与收费报价。本需求文档用于把需求定清楚，并作为后续报价与交付的基线。

| 关键数字 | 数值 |
|---------|------|
| 核心业务板块 | 6+ |
| 当前人均服务客户数 | 100 |
| AI 后目标人均产能 | 500–1000 |
| 工商业务前期沟通占比 | 80% |
| 客户微信号规模 | 5000 人 + 2000 余人 |

**业务范围：**
- **设立与注册**：工商登记、公司注册、企业设立全流程代办
- **日常财务代理**：财务代理、记账报税、财务分析等日常经营支持
- **税务与顾问**：税务案件处理、财务与税务顾问、年度顾问服务

> 一句话定位：这是一家"以人服务为主、客户量大、微信沟通为核心触点、线下口碑获客"的财税服务企业，AI 转型的核心是解放沟通与流程中的重复人力，把服务做成可规模化、可复制的产品。

---

## 二、现状与核心痛点

经过与客户的沟通，企业当前面临四大痛点，集中在"沟通递进、客户分层、咨询承载、汇报留痕"四个环节。

### 痛点 1：客户沟通与跟进效率低

**影响程度：高（9/10）**

在各种场合大量添加客户微信，但后续聊天跟进难以做到位。客户常在工作群和私聊中发起沟通，由于工作群数量过多、信息看不过来，导致回复不及时，直接影响服务体验与转化。

### 痛点 2：客户分类与服务分级缺失

**影响程度：高（8/10）**

缺乏对客户的有效打标与分级。目前对收费较低的客户投入了不成比例的精力，导致服务成本过高，高端客户的价值也未被充分挖掘。

### 痛点 3：咨询类服务耗时过长

**影响程度：中偏高（7/10）**

年度顾问等咨询服务的许多问题，其实可以通过 AI 整理归纳后直接回答。但客户存在惰性——即便自己能查到答案，也习惯在顾问通道里反复询问，消耗大量顾问时间。

### 痛点 4：日报与周报流于形式

**影响程度：中（5/10）**

目前的日报、周报多为敷衍式文档或 PDF，缺乏数据对比，无法与客户的任务进度挂钩，既不能体现服务价值，也无法支撑过程管理。

---

## 三、改进需求总览

围绕上述痛点，企业提出多项改进需求。**当前最高优先级任务是 AI 客服**，用于与客户的沟通与跟进，其中包含三个联动点：

1. **AI 客服机器人与企业知识库**：在企业微信设置客服机器人，机器人背后需要企业知识库支持，涉及财务、税务以及横景补贴政策（以横景补贴政策为主）。
2. **客户管理（画像与打标）**：包括客户画像、打标、分类并筛选出高价值客户。为做好统一管理，需先把客户目前两个微信号（一个 5000 人、一个 2000 余人）里的全部聊天记录导出。
3. **语气蒸馏**：客户希望 AI 回复尽量像真人一样沟通，需将历史聊天中的语气进行"蒸馏"建模；同时 AI 不能一直用同一种语气，否则客户长时间看到一模一样的语气容易识别出是 AI 自动回复，整体体验不佳。

**需求模块总览：**

| # | 需求模块 | 对应痛点 | 优先级 |
|---|---------|---------|--------|
| M1 | AI 客服机器人（含企业知识库、语气蒸馏） | 痛点 1 · 沟通效率 | 最高 |
| M2 | 客户管理（画像与打标） | 痛点 2 · 客户分层 | 高 |
| M3 | 任务与进度管理 | 痛点 4 · 汇报留痕 | 高 |
| M4 | 咨询知识库与 AI 问答 | 痛点 3 · 咨询承载 | 中 |
| M5 | 业务流程标准化（沟通 / 媒体） | 痛点 1 · 沟通效率 | 中 |
| M6 | 新媒体运营 | 获客与口碑 | 中 |
| M7 | 记账系统重构 | 系统底座 | 低（重大投入） |
| M8 | 数字员工应用 | 财务自动化 | 中 |

> 核心目标排序：企业明确表示，AI 转型的第一优先级是减少目前的工作量，在此基础上再谈业务增长与产品化。因此报价与排期应围绕"人效释放"这一主线展开。

## 四、功能模块详述

### M1：AI 客服机器人（最高优先级）

**背景：** 客户沟通与跟进效率低是当前最痛的问题。客户习惯在微信上发起沟通，但人工难以覆盖全部消息，回复不及时。AI 客服机器人用于承接高频、重复的客户咨询，把人工从重复应答中解放出来。

**需求规则：** 本模块包含三个联动子项：

**（1）企业微信客服机器人**
- 在企业微信设置客服机器人，作为客户沟通的统一入口。
- 机器人自动应答高频、重复问题；无法回答或高价值客户可智能转人工。
- 与客户管理（M2）联动：机器人应答记录同步到客户档案，支撑画像与打标。

**（2）企业知识库**
- 机器人背后需要企业知识库支持，覆盖**财务、税务以及横景补贴政策**（以横景补贴政策为主）。
- 知识库采用 RAG 底座：梳理政策法规、补贴政策、行业知识、常见问题与过往案例，向量化后支持检索问答。
- 对无法自动回答的问题智能转人工，并沉淀为新增知识，知识库持续进化。

**（3）语气蒸馏**
- 客户希望 AI 回复尽量像真人一样沟通，需对历史聊天中的语气、措辞、沟通习惯进行"蒸馏"建模。
- **多语气机制**：AI 不能一直用同一种语气，需内置多套语气模板并按场景、客户、时段轮换，避免客户识别出是 AI 自动回复。
- 语气风格需与威吉瑞顾问的真实沟通习惯对齐，保证"像真人、但不像同一个真人"。

**关键交互：** 客户在企业微信发起咨询 → 机器人结合知识库自动应答（附依据来源）→ 高价值或复杂问题转人工 → 应答记录沉淀到客户档案。

**预期效果：** 高频咨询由机器人承接，回复及时性显著提升；人工从重复应答中解放，转向高价值客户服务；语气自然、多变化，客户体感接近真人。

---

### M2：客户管理（画像与打标）（高优先级）

**背景：** 缺乏客户打标与分级，低收费客户占用过多服务精力，高价值客户价值未被充分挖掘。同时客户分散在两个微信号中，缺乏统一管理。

**需求规则：**
- **聊天记录导出**：导出客户目前两个微信号（一个 5000 人、一个 2000 余人）的全部聊天记录，清洗、结构化后统一入库，作为客户管理与语气蒸馏的数据基础。
- **客户画像**：基于聊天记录与业务数据构建客户画像，包括基本信息、服务内容、咨询历史、活跃度等。
- **打标与分类**：建立客户标签体系（按收费档位、服务内容、贡献度、活跃度等多维度打标），自动划分服务等级。
- **高价值客户筛选**：基于标签与画像筛选高价值客户，不同等级对应不同的服务 SLA 与人力投入。

**关键交互：** 顾问在客户详情页维护标签，系统自动给出服务等级建议；管理层可查看客户分层分布与成本结构报表。

**预期效果：** 服务资源向高价值客户倾斜，低价值客户成本受控；客户数据统一管理，支撑 AI 客服与后续运营。

---

### M3：任务与进度管理（高优先级）

**背景：** 日报周报流于形式，缺乏对比，无法与客户任务进度挂钩，过程管理与客户感知都较弱。

**需求规则：** 面向大客户建立项目进度看板，清晰呈现任务的前后进度变化、完成度与预计结束时间；以任务为单元记录进度，替代"敷衍式日报"；自动生成可推送客户的进度周报，用数据体现服务价值。

**关键交互：** 顾问更新任务状态，系统自动计算完成度与剩余周期；周报一键生成并支持导出为 PDF 或推送给客户。

**预期效果：** 进度透明、可追踪，客户看得见服务进程；汇报从"形式"变为"价值证明"。

---

### M4：咨询知识库与 AI 问答（中优先级）

**背景：** 年度顾问等咨询服务的许多问题重复度高，客户惰性导致顾问反复应答，耗时严重。

**需求规则：** 搭建财税政策法律知识库（RAG 底座），沉淀政策法规、行业知识、常见问题与过往案例；AI 基于知识库自动组织答案，覆盖高频咨询；对无法自动回答的问题智能转人工，并沉淀为新增知识。

**关键交互：** 客户在咨询通道提问，AI 先应答并附上依据来源；顾问可审核、补充、沉淀答案，知识库持续进化。

**预期效果：** 砍掉重复咨询，顾问从"答重复题"中解放出来，转向高价值服务；知识资产复利积累。

> 说明：M4 与 M1 的企业知识库共用同一 RAG 底座，可复用建设成果，避免重复投入。

---

### M5：业务流程标准化（中优先级）

**背景：** 工商注册等业务中，前期沟通约占 80% 工作量；媒体发布完全依赖人工，效率低、难坚持。

**需求规则：**
- （a）**沟通流程：** 将前期重复沟通标准化为可复用的流程模板与话术，用工具自动推进，减少人工重复应答。
- （b）**媒体发布：** 接入 AI 替代人工，在公众号、视频号、网站等平台持续自动更新与发布内容。

**关键交互：** 标准化流程向导引导顾问按模板推进；媒体内容由 AI 生成初稿、人工审核后一键发布至多平台。

**预期效果：** 前期沟通人力大幅释放，内容生产从"手工"走向"AI 辅助 + 审核发布"，多平台持续更新成为可能。

---

### M6：新媒体运营（中优先级）

**背景：** 业务目前以线下为主，但小红书、视频号等线上渠道确实能带来客户；客户看到内容后主动咨询，口碑传播效果不错。

**需求规则：** 真人拍摄成本高、难坚持，曾尝试数字人方案（喂素材生成）。希望建立可持续的内容生产与发布机制，覆盖公众号、视频号、网站、小红书等平台，保持稳定更新以持续获客。

**关键交互：** 内容选题库 → AI 生成文案/脚本 → 数字人或图文渲染 → 多平台排期发布 → 获客数据回流。

**预期效果：** 线上获客成为稳定渠道，内容持续更新，口碑传播放大，形成"内容 → 咨询 → 转化"的增长链路。

---

### M7：记账系统重构（低优先级，重大投入）

**背景：** 当前使用"金彩代账"网页版系统，数据在云端，背后与电子税务局关联。若要开发更高级的系统，需跳脱现有记账软件，从产品端重新设计。

**需求规则：** 明确这是一项产品级重构，而非服务端改造。需从产品端重新设计记账流程、数据模型与税务对接，作为企业的长期数字化底座。此项工作量大、周期长，建议作为独立立项分期推进。

**关键交互 / 边界：** 需在功能对齐阶段确认数据迁移方案、与电子税务局的对接方式、私有化或云端部署等关键决策。

**预期效果：** 摆脱对第三方系统的依赖，建立自主可控的记账与税务底座，支撑规模化服务。

---

### M8：数字员工应用（中优先级）

**背景：** 企业新招一位计算机专业员工，正在协助解决初期开票问题，并尝试引入数字员工处理财务相关工作。

**需求规则：** 以开票为切入点，逐步引入数字员工承担可自动化的财务工作（如票据处理、数据录入、对账等）。沉淀为可复用的自动化能力，后续扩展到更多财务场景。

**关键交互：** 开票流程接入自动识别与处理；数字员工任务有清晰日志与人工确认边界，保障财税合规与准确性。

**预期效果：** 从最容易落地的开票场景切入，验证数字员工模式，再逐步扩展到财务工作流。

## 五、优先级与分期建议

依据"先减工作量、再谈增长"的核心诉求，建议按三期推进。**一期以 AI 客服（M1）为核心，联动客户管理（M2）**，快速解决沟通效率与客户分层两大痛点。

### P1：一期 · AI 客服与客户管理（优先交付）

以 **AI 客服机器人（M1）** 为最高优先级，包含企业微信客服机器人、企业知识库（财税 + 横景补贴政策）、语气蒸馏三个联动子项；同步推进 **客户管理（M2）**，先完成两个微信号聊天记录导出，再做画像、打标与高价值客户筛选。

### P2：二期 · 咨询与获客

接入**任务与进度管理（M3）**、**咨询知识库与 AI 问答（M4，复用 M1 知识库底座）**、**业务流程标准化（M5）**、**新媒体运营（M6）**。持续沉淀知识资产、释放沟通人力，并建立线上获客的内容机制。

### P3：三期 · 系统与自动化

推进**数字员工扩展（M8）**，并启动**记账系统重构（M7）**的独立立项。这一阶段投入大、周期长，作为长期数字化底座，需先完成产品与数据方案论证。

**各模块投入规模示意：**

| 模块 | 一期 | 二期 | 三期 | 相对投入 |
|------|------|------|------|---------|
| M1 AI 客服（含知识库、语气蒸馏） | ● |  |  | 中 |
| M2 客户管理 | ● |  |  | 中 |
| M3 任务与进度 |  | ● |  | 低 |
| M4 咨询知识库 |  | ● |  | 中 |
| M5 流程标准化 |  | ● |  | 中 |
| M6 新媒体 |  | ● |  | 中 |

| M7 记账重构 |  |  | ● | 高 |
