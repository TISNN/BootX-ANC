一、品牌名与释义

bootX

启营
boot = 启动 / 部署（FDE 本职） · X = 变量 / 扩展 · 标志以“分段上升的部署路径”为核心
英文 · bootX

启动，而后无限

boot 是系统启动、是产品上线——前端部署工程师的每一次交付，本质都是一次 boot。X 是未知、是变量、是未被定义的可能，呼应 adventureX 一脉的拼接美学。纯字母、无数字、短促锋利。

中文 · 启营

启动，成营

「启」呼应 boot 的启动之意；「营」取自 bootcamp——全球公认的孵化加速器范式。启营天然绑定「社群孵化器」这条业务线：不是把人招进来，而是把他们送上起跑线。

二、品牌定位

一句话：为前端部署工程师而生的「服务客户 + 孵化同行」双引擎品牌。

七、品牌调性

视觉：黑底、白标、可验证的模块关系。不再借用单纯的 X 交叉；标志应让人先读到“部署路径”，再读到品牌名。
语言：工程化、克制、不煽情。像一份好的架构文档：直接、精确、可信。
气质：冷静但有动势，像一个产品从本地环境被逐段推到线上。我们相信上线即正义。

八、Logo 六个方向

这组六个方向分别测试：部署阶梯、上线门、交付接力、模块 B、路径汇合、纯字标。所有图形保留大面积留白，并避开与 X 平台相似的双斜线轮廓。A「Staged Launch」推荐作为主标：它同时表达启动、逐段部署和能力上升，16px 时仍有清楚的轮廓。
A · Staged Launch（主推）
三段上升的部署路径，终点留一枚电蓝状态点。把“上线”做成可识别的动作，而不是一个泛化的 X。
适用：产品图标、favicon、社区头像、衣物刺绣
B · Open Gate
两组 L 形模块拼出开放入口与内侧空间，表达“把产品送出去，也把工程师带进来”。
适用：社区与孵化业务的独立识别
C · Deploy Relay
三个带圆角的环境节点依次交接，从本地、预发到生产。最直观的工程叙事。
适用：服务线图标、课程模块、动效起点
D · Boot Module
从 b 的结构提取出的模块化符号；两个圆角开口像接口，也像系统启动后的两个服务槽位。
适用：工程服务、技术文档页、印刷物
E · Converge
两条路径在中心汇合后继续向前，保留“X 是变量”的精神，但不落入双斜线的既有视觉记忆。
适用：活动、合作、社群连接
F · Staged Launch + 字标
主标与 Space Grotesk 字标的正式组合。字标保持可读，图形承担识别，不再手绘一个 X 来“装饰”。
推荐用于官网首屏、名片、社媒头图

九、字标与使用规则

Space Grotesk 700（主字标）
品牌名本身足够短，字标应只负责阅读。保持统一字距，X 与其他字母同一字体系统，不再拆开重画。
图形 + 字标（推荐主组合）
图形高度约为字标大写高度的 1.15 倍；图形与字标之间保留至少一个模块宽度。小尺寸只用图形，避免压缩细节。
